Tienda web: Fuente: Shopify Admin API — Orders (GraphQL), tienda mompossina.myshopify.com, consultada vía el conector de Shopify en Claude. La app conectada aún no tenía el scope read_reports / acceso a datos protegidos habilitado para usar ShopifyQL, así que este cierre se calculó agregando pedidos individuales (estado de pago confirmado, sin pedidos de prueba). La tienda maneja precios con IVA incluido, así que "Ventas brutas" y "Descuentos" se ajustan dividiendo por 1.19 (mismo factor que usa el dashboard de Medellín) para dejarlos sin IVA; "Subtotal", "IVA", "Envío" y "Ventas totales" salen directo de los totales del pedido (ya netos de devoluciones) sin necesidad de ese ajuste. Cuando ShopifyQL esté disponible, los próximos cierres volverán al método exacto sin este factor. Socios comerciales: proformas/facturas (Wanitta, Casa Viva, Falabella, Learia) subidas manualmente por el usuario para este cierre — no es una fuente conectada en vivo, así que un mes futuro sin nueva carga manual no traerá esta sección actualizada. Solo se cuenta venta real del periodo; este informe no incluye proyección ni forecast. "Unidades vendidas" = unidades netas de devoluciones despachadas en pedidos del periodo. World Office (conciliación contable) se muestra como capítulo pendiente hasta definir su método de conexión; el canal mayorista/socios comerciales ya tiene datos de agosto pero por carga manual, no por conexión automática.
